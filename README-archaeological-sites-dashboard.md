# Επισκεψιμότητα αρχαιολογικών χώρων

Διαδραστικό dashboard για την εξερεύνηση της επισκεψιμότητας αρχαιολογικών χώρων στην Ελλάδα. Είναι πρωτοβουλία του Σωματείου Διάζωμα για την πιο εύκολη και ουσιαστική πρόσβαση σε πολιτιστικά δεδομένα, με έμφαση στην τεκμηρίωση, τον καθαρισμό και την ενοποίηση των ονομασιών της πηγής.

## Τι προσφέρει

- Φίλτρα ανά περιφέρεια, ιστορική ενότητα/νομό της πηγής, είδος χώρου και χρονική περίοδο.
- Γραφήματα επισκέψεων ανά έτος, κατανομής ανά είδος χώρου και επισκεψιμότητας ανά περιφέρεια.
- Κατάταξη χώρων με τις περισσότερες επισκέψεις για τα ενεργά φίλτρα.
- Ιστορική εξέλιξη ανά χώρο: επιλέγοντας έναν χώρο, εμφανίζονται οι ετήσιες επισκέψεις του.
- Εξαγωγή επεξεργασμένων δεδομένων για περαιτέρω ανάλυση.

Το dashboard είναι ένα αυτοτελές HTML αρχείο με ενσωματωμένα δεδομένα και γραφήματα. Ανοίγει απευθείας σε σύγχρονο browser, χωρίς εγκατάσταση, build ή server και χωρίς εξωτερικές βιβλιοθήκες.

## Δεδομένα και πηγές

Πρωτογενής πηγή είναι η ΕΛΣΤΑΤ, «Έρευνα Κίνησης Μουσείων και Αρχαιολογικών Χώρων», πίνακας 04 «Επισκέπτες αρχαιολογικών χώρων κατά μήνα». Η έκδοση που χρησιμοποιείται καλύπτει το 1998 έως τον Μάιο 2026. [Σελίδα δημοσίευσης της ΕΛΣΤΑΤ](https://www.statistics.gr/en/statistics/-/publication/SCI21/2026-M05).

Η αναλυτική χρονοσειρά ανά χώρο αρχίζει το 1998. Τα στοιχεία του 2026 είναι μερικά (Ιανουάριος–Μάιος). Από το 2002 η ΕΛΣΤΑΤ καταγράφει επισκέπτες με εισιτήριο και δωρεάν είσοδο, ενώ για το 1998–2001 η σειρά αφορά εισιτήρια· συνεπώς τα δύο διαστήματα δεν είναι πλήρως συγκρίσιμα. Τα στοιχεία μετρούν επισκέψεις/εισιτήρια, όχι μοναδικά άτομα.

Η πηγή ομαδοποιεί τα στοιχεία ανά παλαιό νομό. Οι ενότητες της πηγής έχουν αντιστοιχιστεί στις 13 σημερινές περιφέρειες, αλλά δεν γίνεται επιμερισμός σε νεότερες περιφερειακές ενότητες όταν ένας παλαιός νομός έχει διασπαστεί.

## Καθαρισμός και ενοποίηση

Οι ονομασίες ελέγχθηκαν σε όλα τα ετήσια φύλλα. Ενοποιήθηκαν ορθογραφικές και τυπογραφικές παραλλαγές, πτώσεις, συντομογραφίες και σημάνσεις υποσημειώσεων όταν ταυτοποιούσαν καθαρά τον ίδιο χώρο. Αμφίσημες ονομασίες ή διαφορετικοί χώροι παραμένουν ξεχωριστοί. Οι αρχικές ονομασίες διατηρούνται στα επεξεργασμένα δεδομένα και στο αρχείο αντιστοιχίσεων.

Ενδεικτικά, οι αρχικές εγγραφές «Μυκήνες», «Θησαυρός Ατρέα» και «Μυκήνες & Θησαυρός Ατρέα» παρουσιάζονται ως ενιαία ιστορική σειρά «Μυκήνες & Θησαυρός Ατρέα». Όταν η πηγή καταγράφει δύο χωριστές εγγραφές, τα ποσά αθροίζονται· όταν δημοσιεύει ήδη κοινό σύνολο, αυτό διατηρείται. Ο τύπος «Αρχαιολογικό σύμπλεγμα» για αυτή τη σειρά και οι υπόλοιποι τύποι χώρων είναι εκτιμήσεις για τις ανάγκες του dashboard, όχι επίσημες κατηγορίες της ΕΛΣΤΑΤ.

Η τρέχουσα επεξεργασμένη έκδοση περιλαμβάνει 3.210 ετήσιες εγγραφές, 181 συνδυασμούς χώρου και ενότητας πηγής και 133 αρχικές ονομασίες στο αρχείο αντιστοιχίσεων. Αναλυτικές σημειώσεις, ορισμοί και γνωστές αποκλίσεις υπάρχουν στο [`data/README.md`](data/README.md).

## Αρχεία

```text
.
├── README.md                                      # αυτό το αρχείο, όταν μεταφερθεί στον αυτόνομο φάκελο
├── index.html                                     # αρχική σελίδα (εισαγωγή και θεματικές ενότητες)
├── archaeological-sites/index.html                # διαδραστικό dashboard επισκεψιμότητας
├── scripts/
│   └── build_dashboard_data.py                    # παράγει/ελέγχει τα ενσωματωμένα δεδομένα
└── data/
    ├── README.md                                  # τεκμηρίωση πηγών και μεθοδολογίας
    ├── elstat_archaeological_sites_1998_may2026.xlsx
    ├── archaeological_site_visits_by_site_1998_2026.csv
    ├── archaeological_site_name_crosswalk_1998_2026.csv
    └── archaeological_site_visits_by_source_unit_1998_2026.csv
```

Το πρωτογενές αρχείο XLSX διατηρείται αυτούσιο. Τα CSV περιέχουν τις επεξεργασμένες ετήσιες εγγραφές ανά ενοποιημένο χώρο, τις αντιστοιχίσεις αρχικών και καθαρισμένων ονομασιών, καθώς και τα ετήσια σύνολα ανά ενότητα της πηγής.

## Ενημέρωση δεδομένων

Τα CSV στο `data/` είναι η πηγή αλήθειας. Τα δεδομένα μέσα στο `archaeological-sites/index.html` παράγονται από αυτά:

```bash
python3 scripts/build_dashboard_data.py           # ξαναγράφει τα ενσωματωμένα δεδομένα
python3 scripts/build_dashboard_data.py --check   # ελέγχει συνέπεια CSV και HTML χωρίς αλλαγές
```

Το `--check` εκτελείται και αυτόματα σε κάθε push ή pull request (`.github/workflows/validate.yml`).

## Τοπική χρήση

1. Κατεβάστε ή αντιγράψτε το project μαζί με τον φάκελο `data/`.
2. Ανοίξτε το `archaeological-sites/index.html` σε σύγχρονο browser.
3. Επιλέξτε φίλτρα και πατήστε σε έναν χώρο της κατάταξης για να δείτε την ιστορική του εξέλιξη.

Δεν απαιτούνται λογαριασμοί, κλειδιά API ή εξαρτήσεις για να λειτουργήσει το dashboard τοπικά.
